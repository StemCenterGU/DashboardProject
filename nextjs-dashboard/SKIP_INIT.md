# Skip Init - components.json Already Exists!

Since `components.json` already exists, you can **skip the init step** and go straight to installing components!

## ✅ Just Install Components

Run this command to install all components at once:

```bash
npx shadcn@latest add button card input label alert dropdown-menu avatar
```

Or install them one by one:

```bash
npx shadcn@latest add button
npx shadcn@latest add card
npx shadcn@latest add input
npx shadcn@latest add label
npx shadcn@latest add alert
npx shadcn@latest add dropdown-menu
npx shadcn@latest add avatar
```

## After Installation

1. Restart your dev server:
   ```bash
   npm run dev
   ```

2. Visit http://localhost:3000

You should now see the login page! 🎉

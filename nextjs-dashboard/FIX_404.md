# Fix 404 Errors

## Quick Fix Steps

### Step 1: Clear Next.js Cache

Stop your dev server (Ctrl+C) and run:

```bash
# Delete .next folder
rmdir /s /q .next

# Or on PowerShell:
Remove-Item -Recurse -Force .next
```

### Step 2: Restart Dev Server

```bash
npm run dev
```

### Step 3: Hard Refresh Browser

- **Chrome/Edge**: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
- **Firefox**: Ctrl+F5

## If Still Getting 404

### Check These URLs:

1. **Dashboard**: http://localhost:3000/dashboard
2. **Scheduling**: http://localhost:3000/dashboard/scheduling
3. **Charts**: http://localhost:3000/dashboard/charts
4. **Calendar**: http://localhost:3000/dashboard/calendar

### Verify Files Exist:

All these files should exist:
- ✅ `app/(dashboard)/dashboard/page.tsx`
- ✅ `app/(dashboard)/scheduling/page.tsx`
- ✅ `app/(dashboard)/charts/page.tsx`
- ✅ `app/(dashboard)/calendar/page.tsx`
- ✅ `app/(dashboard)/profile/page.tsx`
- ✅ `app/(dashboard)/settings/page.tsx`

## Common Issues

### Issue 1: Route Groups Not Working
- Route groups `(dashboard)` should work in Next.js 14+
- Make sure you're using Next.js 14+

### Issue 2: Build Cache
- Delete `.next` folder
- Restart dev server

### Issue 3: TypeScript Errors
- Check terminal for compilation errors
- Fix any TypeScript errors first

## Debug

Check the terminal where `npm run dev` is running - are there any errors?

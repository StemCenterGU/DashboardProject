========================================
PUSH CODE TO GITHUB - MANUAL COMMANDS
========================================

Repository URL: git@github.com:AvishManiar21/DashboardProject.git

Open Command Prompt or PowerShell in this folder and run:

1. Navigate to project:
   cd "C:\Users\avish\OneDrive\Desktop\dashboard_project\stem-face-dashboard"

2. Initialize git (if not done):
   git init

3. Add all files:
   git add .

4. Create commit:
   git commit -m "Initial commit - DashboardProject"

5. Add remote:
   git remote add origin git@github.com:AvishManiar21/DashboardProject.git

6. Set branch:
   git branch -M main

7. Push to GitHub:
   git push -u origin main

========================================
IF SSH DOESN'T WORK - USE HTTPS INSTEAD
========================================

If you get authentication errors with SSH, use HTTPS:

1. Change remote to HTTPS:
   git remote set-url origin https://github.com/AvishManiar21/DashboardProject.git

2. Push again:
   git push -u origin main

3. When prompted:
   Username: AvishManiar21
   Password: Use Personal Access Token (not your GitHub password)
   
   Create token: https://github.com/settings/tokens
   - Click "Generate new token (classic)"
   - Select scope: repo
   - Copy token and use as password
